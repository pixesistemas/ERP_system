# V3.8 — Consistencia fiscal y financiera

- Sincronización reforzada de bancos, cheques y proveedores entre módulos.
- Migración automática desde claves antiguas de localStorage.
- Estados de cheques normalizados para cartera, depósitos y órdenes de pago.
- Libro IVA Ventas/Compras con solapas, comprobantes fiscales únicamente, totales y diferencia entre débito y crédito fiscal.
- Reporte A4 horizontal independiente para Libro IVA.
- Descuento habitual por cliente persistido en SQLite y editable desde el CRUD.
- Código de comprobante ARCA impreso con tres dígitos en las plantillas oficiales.
