# Conversation Engine

## Responsabilidad

Administra conversaciones comerciales iniciadas desde:

- WhatsApp
- React
- API
- n8n
- IA

## Funciones actuales

- Crear conversaciones.
- Recuperar conversaciones activas.
- Guardar estado y contexto.
- Asociar Workspace.
- Asociar Business Session.
- Finalizar o cancelar conversaciones.

## No hace

- No emite facturas.
- No calcula precios.
- No mueve stock.
- No genera PDFs.
- No interpreta IA todavía.

Esas tareas se delegan a otros motores.
