92. REGLAS IMPORTANTES PARA IMPLEMENTAR
=====================================================

1. No inventar productos.
2. No inventar precios.
3. No inventar stock.
4. No inventar descuentos.
5. No inventar saldo de cuenta corriente.
6. No inventar direcciones.
7. Buscar siempre los datos reales en el ERP.
8. Usar contexto para respuestas como "ese", "esa", "sí", "5", "el primero".
9. Permitir varios productos en un mismo mensaje.
10. Permitir que el cliente corrija el pedido en cualquier momento.
11. Mantener un carrito/pedido borrador por conversación.
12. No confirmar cada producto si no existe ambigüedad.
13. Confirmar siempre antes de registrar definitivamente el pedido.
14. Confirmar acciones sensibles: facturación, cuenta corriente, cancelación y cambios críticos.
15. Si una búsqueda devuelve muchos productos, mostrar pocas opciones relevantes.
16. Entender abreviaturas y errores ortográficos.
17. Normalizar mayúsculas, minúsculas y tildes.
18. Considerar singular/plural.
19. Considerar códigos de barra alternativos.
20. Considerar presentaciones y equivalencias: unidad, pack, caja, bulto.
21. Mantener memoria del cliente y del pedido actual.
22. Consultar pedidos anteriores cuando el cliente diga "lo mismo de la otra vez".
23. No confundir una consulta de precio con una confirmación de pedido.
24. Si el cliente dice "solo presupuesto", no generar pedido definitivo.
25. Si el cliente dice "no lo cargues todavía", mantener borrador.
26. Si hay falta de stock, ofrecer alternativas reales.
27. Aplicar lista de precios del cliente desde el ERP.
28. Aplicar promociones desde el ERP, no desde la IA.
29. Respetar condición de venta y límite de crédito.
30. Registrar auditoría de lo interpretado y lo ejecutado.
