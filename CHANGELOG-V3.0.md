# V3.0

- POS operable con teclado: F2 código, F4 descripción, F8 cliente, F10 cobrar y Ctrl+1..4 para ventas abiertas.
- Tecla `*` en medios de pago para completar automáticamente el importe faltante.
- Campos numéricos seleccionan todo al recibir foco, con comportamiento tipo calculadora.
- Confirmación previa: Factura electrónica o Nota de venta X.
- Cada pestaña conserva carrito, cliente, condición de pago y observaciones de forma independiente.
- Código `precio*código` usa coincidencia exacta y nunca reemplaza por productos parecidos.
- Recibo PDF compacto con original y copia en una hoja A4, línea punteada y logo configurable.
- Configuración de URL del logo y opción de recibo doble copia.
- Conversación: confirmación explícita de cliente incluso cuando existe una sola coincidencia.
- Conversación: entiende frases como “cemento cantidad 6 y cal cantidad 10”.
- La palabra “no” ya no cancela automáticamente toda la operación.
- CRUD visual inicial de proveedores.
- Cartera visual de cheques con estados y vencimientos.
