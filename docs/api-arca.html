API ARCA para sistemas externos

Para tu sistema en FoxPro · mismo certificado y punto de venta del ERP · PixeSistemas

1. Activación

  1. Superadmin → Módulos → tildar "API ARCA (sistemas externos)" en la empresa.
  2. Obtener la API Key: ERP → Bandeja WhatsApp → tarjeta de conexión → campo "API Key para n8n".
  3. (Opcional) Subdominio arca.pixesistemas.com.ar: Cloudflare (registro A "arca" → IP del servidor, Solo DNS) + Nginx Proxy Manager (Proxy Host → 172.17.0.1:3100 + Let's Encrypt).

2. Dirección y autenticación

https://arca.pixesistemas.com.ar/api/v1/arca   (o https://erp.pixesistemas.com.ar/api/v1/arca)

Headers:
  x-api-key: TU_API_KEY
  Content-Type: application/json

3. Estado del servicio

GET /api/v1/arca/estado

{ "ok": true,
  "empresa": { "id": 4, "nombre": "Seitu", "cuit": "20234143403", "condicionIVA": "RESPONSABLE INSCRIPTO", "production": true, "puntoVenta": 5 },
  "fiscal": { "certificado": true, "ambiente": "PRODUCCION" } }

4. Último comprobante autorizado

GET /api/v1/arca/ultimo-comprobante?punto_venta=5&tipo=6

Códigos de tipo: 1 Factura A · 6 Factura B · 11 Factura C · 3 NC A · 8 NC B · 13 NC C · 2 ND A · 7 ND B · 12 ND C.

{ "ok": true, "punto_venta": 5, "tipo": 6, "ultimo": 1234 }

5. Emitir comprobante

POST /api/v1/arca/comprobantes

{
  "operacion": "FACTURA",
  "punto_venta": 5,
  "concepto": 1,
  "cliente": {
    "cuit": "20111111112",
    "razon_social": "CLIENTE DE PRUEBA",
    "condicion_iva": "CONSUMIDOR FINAL"
  },
  "items": [
    { "codigo": "A1", "descripcion": "Producto 1", "cantidad": 2, "precio_unitario": 1500, "descuento": 0, "iva": 21 }
  ]
}
  • operacion: FACTURA (por defecto), NOTA_CREDITO o NOTA_DEBITO.
  • La letra A/B/C se resuelve sola según la condición IVA de la empresa y del cliente.
  • condicion_iva del cliente: RESPONSABLE INSCRIPTO, MONOTRIBUTO, EXENTO o CONSUMIDOR FINAL.
  • Para notas, agregar el comprobante original: "cbte_asoc": [ { "tipo": 6, "puntoVenta": 5, "numero": 1234 } ]

Respuesta:

{ "ok": true, "cae": "75123456789012", "cae_vencimiento": "2026-10-05", "numero": 1235,
  "punto_venta": 5, "tipo_comprobante": 6, "letra": "B", "nombre_comprobante": "FACTURA B",
  "importe_neto": 3000, "importe_iva": 630, "importe_total": 3630,
  "resultado": "A", "observaciones": null, "errores": null }

6. Errores

CódigoSignificado
400Faltan datos (items, tipo, cbte_asoc en notas)
401Falta o es inválida la x-api-key
403El módulo "API ARCA" no está tildado para la empresa
422ARCA rechazó el comprobante (mirar errores/observaciones)
502No se pudo consultar ARCA (red/certificado)
503ARCA no respondió: reintentar (el intento queda registrado)

7. Ejemplo desde FoxPro (Visual FoxPro)

LOCAL loHttp, lcUrl, lcJson, lcResp
loHttp = CREATEOBJECT("WinHttp.WinHttpRequest.5.1")
lcUrl = "https://arca.pixesistemas.com.ar/api/v1/arca/comprobantes"

lcJson = '{"operacion":"FACTURA","punto_venta":5,' + ;
         '"cliente":{"cuit":"20111111112","razon_social":"CLIENTE","condicion_iva":"CONSUMIDOR FINAL"},' + ;
         '"items":[{"codigo":"A1","descripcion":"Producto","cantidad":1,"precio_unitario":1000,"iva":21}]}'

loHttp.Open("POST", lcUrl, .F.)
loHttp.SetRequestHeader("Content-Type", "application/json")
loHttp.SetRequestHeader("x-api-key", "TU_API_KEY")
loHttp.Send(lcJson)

lcResp = loHttp.ResponseText   && JSON con cae, numero, vencimiento...
Importante: la API emite el comprobante y devuelve el CAE; cada intento queda registrado en el ERP para auditoría. El comprobante no se registra como venta en el ERP (tu FoxPro sigue manejando su venta). Si querés que además quede la venta en el ERP, se agrega con un campo registrar: true.
