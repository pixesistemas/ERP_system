# AFIP Conversacional Demo V2.3

## Correcciones

- Las facturas nuevas confirmadas desde el chat usan el proceso `VENTA`.
- `FACTURAR_DOCUMENTO` queda reservado para convertir un presupuesto, remito u otro documento existente.
- El resumen previo muestra el nombre del cliente resuelto cuando está disponible.

## Punto de venta avanzado

- Diseño basado en el segundo sistema POS entregado.
- Cuatro ventas abiertas en pestañas independientes.
- Datos de cliente, documento, condición de IVA y condición de pago.
- Entrada rápida por código de barras o descripción.
- Precio y cantidad editables.
- Grilla de artículos con descuentos y subtotales.
- Descuento general, recargo, observaciones, cantidad de artículos y total.
- Envío del carrito al mismo asistente conversacional.

## Menú ERP

Se incorporó el menú visual de ventas, gestión, finanzas y configuración. Los módulos todavía no conectados aparecen como vistas de próxima etapa para permitir mostrar la evolución general del producto.
